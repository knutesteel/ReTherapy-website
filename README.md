# ReTherapy Massage Website

Public website for ReTherapy Massage in Apollo Beach, Florida.

## Development

```bash
npm install
npm run dev
```

## Deployment

The `main` branch is intended to deploy automatically through Vercel. Add `retherapy.com` and `www.retherapy.com` to the Vercel project, then configure the exact DNS records Vercel provides at Network Solutions. Do not change MX, SPF, DKIM, or DMARC records.
